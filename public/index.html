SHARED COMPUTE FOR LARGE AI MODELS

Run models too large for one machine.

CortexGrid splits large models across member hardware. Use the network while contributing your machine, or run a dedicated worker and earn CTX for verified inference.

Open CortexGrid Chat

Join CortexGrid

Choose how this machine will participate.

Chat in this page while your local compute bridge hosts an assigned model stage. The bridge keeps your worker identity on your machine.

Start local compute to enable chat

Run this command on your machine and leave it open. It joins the compute network, then opens this page with a private connection.

make chat-browser COORDINATOR_URL=http://COORDINATOR_IP:65534 ADVERTISE_HOST=THIS_MACHINE_IP TERM_MEMORY_GIB=24

Start the local compute bridge above. It will reconnect this page automatically.

A dedicated worker stays available for model stages and inference. It earns CTX at the same rate without opening the chat interface.

make join NODE_ID=my-node MEMORY_GIB=24 COORDINATOR_URL=http://COORDINATOR_IP:65534 ADVERTISE_HOST=THIS_MACHINE_IP

Rewards require completed, verified work. No CTX balance is needed to join.

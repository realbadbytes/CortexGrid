# Terminus web font

These files are the unmodified Terminus OpenType bitmap fonts distributed by
the Ubuntu/Debian `fonts-terminus-otb` package:

- `terminus-normal.otb`
- `terminus-bold.otb`

Install or refresh them from the system repository with:

```sh
sudo apt-get install fonts-terminus-otb
```

The font is licensed under the SIL Open Font License 1.1. The package's
copyright and license text is included in `LICENSE-Terminus.txt`.
